# Changelog

All notable changes to this project will be documented in this file.

The format follows Keep a Changelog style, and this project uses date-based release notes until version tags are added.

## Unreleased

### Added

- Streamlit medicine reminder app.
- Real-time refresh for current reminders.
- Medicine creation, taken status, and deletion.
- Health tracker for temperature, pulse, blood pressure, blood sugar, BMI, water, sleep, and mood.
- Health analyzer with wellness score, alerts, warnings, healthy signs, logs, and charts.
- Local JSON data storage in `data.json`.
- User, contributor, and agent documentation.
- AGPLv3 license.

### Changed

- Updated the project from a static/Flask direction to a Streamlit app.

### Notes

- Health guidance is simplified and non-diagnostic.
